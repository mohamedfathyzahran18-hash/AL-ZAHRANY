# الزهراني – نظام محاسبي

نظام محاسبي متكامل للقيد المزدوج، دفتر الأستاذ، ميزان المراجعة، والقوائم المالية (قائمة الدخل، المركز المالي، والتدفقات النقدية) مع تصدير إلى Excel، دعم العمل دون اتصال بالإنترنت، ومزامنة سحابية عبر **Firebase Firestore**.

## خطوات إعداد Firebase قبل الرفع على GitHub
1. أنشئ مشروعًا جديدًا في [Firebase Console](https://console.firebase.google.com/).
2. فعّل **Firestore Database** وأنشئ قاعدة البيانات.
3. أضف تطبيق ويب (**Web App**) وانسخ بيانات `firebaseConfig`.
4. افتح ملف `index.html` واستبدل القيم داخل كائن `firebaseConfig` ببيانات مشروعك الحقيقية.
5. ارفع ملفات المشروع (`index.html`, `manifest.json`, `sw.js`, `README.md`) إلى مستودعك على GitHub وفعّل **GitHub Pages** من `Settings > Pages`.

## مجموعات Firestore المستخدمة
- `users`: حفظ بيانات تسجيل الدخول (الاسم، رقم الهاتف، آخر دخول، ومعلومات المتصفح).
- `journal_entries`: حفظ القيود المحاسبية المرتبطة برقم هاتف المستخدم.
- `activity_logs`: سجل الأحداث (تسجيل الدخول، حفظ قيد، حذف قيد، مسح البيانات).
